AlienV4 验证系统 · 域名 yh-team.org · 端口 14639 · 简体中文

一、概览

为 AlienV4 客户端提供账号授权与机器码绑定验证。包含游戏端验证接口、管理后台接口、管理网站与本文档。

环境Base URL
生产https://yh-team.org
本地http://localhost:14639

统一返回结构：{ "success":bool, "code":str, "message":str, ... }

二、游戏端验证

POST /api/v1/auth/verify

// 请求
{
  "username": "玩家用户名",
  "password": "账号密码",
  "machineCode": "本机机器码(SHA-256)",
  "clientType": "alienv4"
}
// 响应（通过）
{
  "success": true, "code": "OK",
  "token": "会话令牌", "expireAt": 1735689600000,
  "bound": true, "needsBind": false
}

逻辑：账号不存在→NOT_PURCHASED；密码错→INVALID_CREDENTIALS；clientType 不符→NOT_PURCHASED；过期→EXPIRED；机器码空→自动绑定；不一致→MACHINE_MISMATCH。游戏端验证不通过一律崩溃退出。

三、账号信息

GET /api/v1/account/info?token=会话令牌

四、管理员接口

非登录接口需请求头 X-Admin-Token: <token>

方法路径说明
POST/api/v1/admin/login登录（密码 admin123999）
GET/api/v1/admin/accounts账号列表
POST/api/v1/admin/account添加/授权账号
POST/api/v1/admin/account/renew续期
POST/api/v1/admin/account/delete删除账号
POST/api/v1/admin/account/resetmachine解绑机器码
GET/api/v1/admin/products产品列表
POST/api/v1/admin/product添加产品
POST/api/v1/admin/product/delete删除产品

五、curl 示例

# 登录
curl -s -X POST http://localhost:14639/api/v1/admin/login \
  -H 'Content-Type: application/json' -d '{"password":"admin123999"}'

# 添加账号
curl -s -X POST http://localhost:14639/api/v1/admin/account \
  -H "X-Admin-Token: $ADMIN" -H 'Content-Type: application/json' \
  -d '{"username":"test","password":"test123","clientType":"alienv4","durationDays":30}'

# 游戏端验证
curl -s -X POST http://localhost:14639/api/v1/auth/verify \
  -H 'Content-Type: application/json' \
  -d '{"username":"test","password":"test123","machineCode":"ABC123","clientType":"alienv4"}'
